# Railway deployment checklist

This checklist deploys the clean factory without GitHub. It does not use the
quarantined n8n project.

## Create the service

1. Open the Railway project `patient-generosity`.
2. Confirm the PostgreSQL service is present and private.
3. Add an empty service named `factory-api`.
4. On your laptop, open PowerShell in this folder:

```powershell
Set-Location "C:\Users\AK_01\Desktop\COPILOT COWORK\factory"
railway login
railway link
railway up
```

Choose the `patient-generosity` project, its production environment, and the
`factory-api` service when prompted.

## Add variables privately in Railway

Set these in the Railway dashboard, not in chat and not in source files:

```text
APP_ENV=production
APP_PAUSED=true
MOCK_PUBLISHING=true
YOUTUBE_ENABLED=false
INSTAGRAM_ENABLED=false
PUBLIC_BASE_URL=https://factory-api-production-2fae.up.railway.app
TELEGRAM_BOT_USERNAME=devilmoneyprinter_bot
TELEGRAM_OWNER_IDS=1112018699
TELEGRAM_LANGUAGE=bilingual
MAX_DAILY_PUBLICATIONS=6
MAX_CONCURRENT_JOBS=1
MAX_STORAGE_GB=4
ADMIN_API_TOKEN=<random secret generated by you>
TELEGRAM_BOT_TOKEN=<BotFather token>
TELEGRAM_WEBHOOK_SECRET=<random secret generated by you>
DATABASE_URL=<Railway reference to the PostgreSQL URL>
```

Keep `MOCK_PUBLISHING=true` until the health checks and Telegram webhook have
been tested. Do not enable YouTube or Instagram yet.

## Optional custom domain

`supremejaat.pro` is not required. The Railway-generated HTTPS URL is enough
for the Telegram webhook. Only attach the custom domain if you want a branded
endpoint later. The app still exposes no dashboard and no public admin API.

## Telegram webhook

After the service is healthy, the application will receive updates at:

```text
https://factory-api-production-2fae.up.railway.app/telegram/webhook
```

The webhook must be registered with Telegram using the bot token and secret
from Railway. Do this from a private local terminal or a protected Railway
operation, never by placing the token in a URL shared in chat.

## First acceptance checks

- `GET /health` returns `status: ok`.
- `GET /api/status` reports paused and mock mode.
- `/start`, `/status`, `/queue`, `/pause`, and `/resume` work for the owner ID.
- A non-owner Telegram ID is rejected.
- `/generate` creates a queued job.
- Approval changes only that job version.
- Publication remains blocked while paused.
- No YouTube or Instagram request is made.
